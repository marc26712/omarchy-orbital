# orbital

Thème omaLauncher / Omarchy — Culture — Iain M. Banks

Un Orbital : l'anneau habitat de la Culture, vu depuis l'espace. Anneau incliné, terminateur jour/nuit, lumières des villes sur la face nocturne, liseré atmosphérique. Palette noir bleuté + or pâle.

## Install

Settings → Theme → coller l'URL du dépôt :

    github.com/marc26712/omarchy-orbital

## Contenu

- `colors.toml` — palette (dark)
- `backgrounds/` — 3 fonds 1080×2400 (9:20)

## Crédits images

Fonds générés procéduralement (rendu interne, terrain périodique + étoiles). Libre d'usage.
